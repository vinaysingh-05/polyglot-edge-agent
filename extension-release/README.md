# Polyglot Proxy Gate - Chrome Extension Release

Browser extension for intercepting and routing prompts through Polyglot Proxy.

## How to Install (for Users)

1. Download **`polyglot-proxy-gate-v1.0.zip`** from this release.
2. Extract (unzip) the zip file on your computer.
3. Open Google Chrome (or Edge / Brave).
4. Go to `chrome://extensions` (or `edge://extensions` in Edge).
5. Enable **Developer mode** (toggle in the top-right corner).
6. Click **Load unpacked** (top-left).
7. Select the unzipped folder containing `manifest.json`.
8. Done! Pin the extension to your toolbar to check connection status.
